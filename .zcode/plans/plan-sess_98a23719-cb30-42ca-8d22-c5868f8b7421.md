# 去除 Spring Boot，改造为纯 Spring Framework 项目

## 现状依据（已核实）

- main 代码里用 Boot 类的只有 3 个文件：`InnovateXApplication`、`config/DruidConfig`、`config/ProxyServletConfig`
- test 里只有 2 个 Boot 冒烟测试；无 assertj/mockito 依赖
- 全部 15 个主题 demo、`SpringCodeTest`（XML）都是纯 Spring Framework，不受影响
- 所需替代依赖本地仓库全有（离线可行）：spring-framework-bom 6.2.19、aspectjweaver 1.9.25.1、jackson-databind 2.21.4、jakarta.annotation-api 2.1.1、junit-jupiter 5.12.2、hamcrest 3.0、druid 1.2.28、maven-surefire 3.5.6 / compiler 3.14.1
- 唯一本地缺失：jakarta.servlet-api（mvc 包的 `jakarta.servlet.*` 编译需要）——需下载一个小 jar；若失败则改用 tomcat-embed-core 10.1.55（本地有，内含 servlet API）

## 改动清单

### 1. pom.xml 重写

- 删除 `spring-boot-starter-parent`、`spring-boot-maven-plugin`
- 依赖替换（版本全部对齐本地仓库）：
  - `spring-framework-bom 6.2.19` 管理：`spring-context`、`spring-webmvc`、`spring-jdbc`、`spring-test`(test)
  - 新增：`org.aspectj:aspectjweaver 1.9.25.1`（@Aspect 支持，原由 starter-aop 传递）、`jackson-databind 2.21.4`（JSON 演示）、`jakarta.annotation-api 2.1.1`（@PostConstruct/@Resource）、`jakarta.servlet-api 6.0.0`、`com.alibaba:druid 1.2.28`（裸包替换 druid-spring-boot-3-starter，XML 数据源在用）
  - test 新增：`junit-jupiter 5.12.2`、`hamcrest 3.0`（替换 starter-test）
  - 保留：netty-all、hutool-all、lombok、h2(runtime)
  - 删除：starter-web/aop/actuator/test、druid starter、mybatis 两个 starter、smiley-http-proxy-servlet、postgresql 驱动（已无引用）
- build：`maven-compiler-plugin` + `maven-surefire-plugin 3.5.6` 显式声明，properties 加 `maven.compiler.release=21`、UTF-8

### 2. 删除 Boot 专属代码（按用户决策）

- `InnovateXApplication.java`（主类）
- `config/DruidConfig.java`（含 `app.datasource.enabled` 开关——只为 Boot 启动而存在，XML/H2 路径不依赖它）
- `config/ProxyServletConfig.java`（HLS 代理残留）→ config 包清空
- `netty/AsyncController.java`（长轮询，用户选择删除）

### 3. 删除测试与资源

- 测试：`InnovateXApplicationTests`、`InnovateXApplicationH2ProfileTests`
- 资源：`application.yml`、`application-druid.yml`、`application-h2.yml`（Boot 配置机制）、`mybatis/`（无 mapper）、`cms/CMS_API`（TV 残留）、`logback-spring.xml`（Boot 日志机制，内容本来就全被注释）
- 保留：`app*.properties`/`override.properties`（XML 占位符在用）、`message*.properties`、全部 `*-context.xml`/`spring-advanced.xml`、`transaction/schema.sql`、`xmltest/schema.sql`

### 4. README 更新

描述改为纯 Spring Framework 试验场；删除 Profile/无数据库模式章节；Netty 表去掉 AsyncController 行；运行说明改为纯 Maven 测试命令。

2. `./mvnw package -DskipTests` → 纯 jar 可打包
3. grep 确认 src 下不再有任何 `org.springframework.boot` 引用
