# Spring 底层机制 Demo 补全计划（高+中优先级，13 主题）

## 总体原则

- **不动现有代码**：现有 `spring` 包 26 个类和 `spring-context.xml`、`SpringCodeTest` 保持原样，全部为**新增**。
- **按主题建子包**：新增内容放在 `com.alec.InnovateX.spring.<主题>` 下，语义化命名，不再平铺。
- **验证方式沿用现有模式**：每个主题一个测试类，纯 `AnnotationConfigApplicationContext` / `ClassPathXmlApplicationContext` 手动建容器（不用 `@SpringBootTest`，不依赖 Boot 主应用和外部 PostgreSQL），控制台输出现象 + JUnit 断言。
- **注释与输出用中文**，与现有风格一致。

## 唯一的依赖变更

`pom.xml` 新增 `com.h2database:h2`（**test scope**，仅事务主题使用，通过 `EmbeddedDatabaseBuilder` 建内存库 + 启动建表，不碰现有 Druid/PostgreSQL 配置）。

## 各主题内容

**① annotation** — `@ComponentScan` 配置类；`@Autowired` 三种注入方式（字段/setter/构造器）+ required=false + List/Map 注入所有实现；`@Qualifier`/`@Primary`/`@Resource` 区别；`@Value` 占位符；`@PostConstruct`/`@PreDestroy`（jakarta）。

**② javaconfig** — `@Configuration` full 模式 CGLIB 代理（同一 config 类调用 `@Bean` 方法验证单例）vs lite 模式（`proxyBeanMethods=false`）；`@DependsOn`/`@Lazy`；`@PropertySource`；`@Import` 三种形式（普通类 / 自定义 `ImportSelector` / 自定义 `ImportBeanDefinitionRegistrar`）；自定义 `Condition` + `@Conditional`；`@Profile` + `Environment` API（激活 profile、PropertySource 层级）；自定义 `BeanDefinitionRegistryPostProcessor`。

**③ scope** — singleton vs prototype（两次 getBean 对比 + prototype 不回调 destroy 的现象）；`@Scope(proxyMode=TARGET_CLASS)` 作用域代理；自定义 `Scope` 实现 + `CustomScopeConfigurer`；**可运行的循环依赖失败示例**：构造器注入抛 `BeanCurrentlyInCreationException`、prototype 循环抛异常（`assertThrows` 断言）；`@Lazy` 注入点打破构造器循环；**三级缓存验证**：自定义 `SmartInstantiationAwareBeanPostProcessor#getEarlyBeanReference`，观察 AOP Bean 循环依赖时早期代理的生成。

**④ aop** — `@AspectJ` 注解式全套通知（`@Pointcut`/`@Before`/`@AfterReturning`/`@AfterThrowing`/`@Around`/`@After` + JoinPoint）；编程式 `ProxyFactory`；**JDK vs CGLIB 对比**（有接口走 JDK、无接口走 CGLIB、final 类 CGLIB 报错的差异）；切点表达式进阶（`within`/`target`/`args`/`bean()`）；自调用失效场景 + `@EnableAspectJAutoProxy(exposeProxy=true)` + `AopContext.currentProxy()` 修复。

**⑤ transaction（H2）** — `TxConfig`：`EmbeddedDatabaseBuilder` + `schema.sql`（建 account 转账表）+ `DataSourceTransactionManager` + `@EnableTransactionManagement`；`@Transactional` 基本回滚；**7 种传播行为**重点演示 REQUIRED（同生共死）、REQUIRES_NEW（内层独立回滚）、NESTED（savepoint 部分回滚），其余四种（SUPPORTS/NOT_SUPPORTED/MANDATORY/NEVER）配行为说明；隔离级别聚焦 READ_COMMITTED vs SERIALIZABLE 的不可重复读对比（H2 2.x 不支持脏读）；**失效场景四连**：自调用、非 public 方法、异常被 catch 吞掉、checked 异常默认不回滚 vs `rollbackFor`；`@TransactionalEventListener`（AFTER_COMMIT）。

**⑥ event** — `@EventListener` 注解式（对比现有接口式）；泛型事件（`ResolvableType` 按载荷类型分发）；异步事件（`@EnableAsync` + `@Async` 监听器）；监听器 `@Order` 顺序与异常传播。

**⑦ aware** — 补齐 7 个：`BeanFactoryAware`、`EnvironmentAware`、`ApplicationEventPublisherAware`、`MessageSourceAware`、`ResourceLoaderAware`、`EmbeddedValueResolverAware`、`ImportAware`（归入一个聚合 demo Bean，逐个输出回调时机）。

**⑧ lifecycle** — `SmartInitializingSingleton`（所有单例预创建完成后回调一次）；`SmartLifecycle`（`getPhase`/`autoStartup`、start/stop 顺序）与已有 `LifecycleProcessor` demo 呼应对比。

**⑨ xmladvanced** — 新增 `spring-advanced.xml`：bean 继承（parent/abstract）、`alias`、静态工厂（factory-method）/实例工厂（factory-bean）、`lookup-method` 方法注入（单例依赖多例）、`replaced-method`、`<map>`/`<set>`/`<props>` 集合注入、`util:` 命名空间、`depends-on`/`lazy-init`/`autowire=byType|byName`。

**⑩ spel** — `ExpressionParser`：字面量/运算符/三元/Elvis/正则、属性与方法调用、集合投影 `.!?`；`@Value` 中使用 SpEL 的 Bean。

**⑪ resource** — `Resource` 各实现（ClassPath/FileSystem/Url）与 `ResourceLoader`/`ResourcePatternResolver`（`classpath*:` + Ant 通配）；自定义 `Converter` + `ConversionService`；自定义 `PropertyEditor`；`DataBinder` + `Validator`。

**⑫ cache** — `@EnableCaching` + `ConcurrentHashMapCacheManager`（Spring 自带内存实现，无外部依赖）+ `@Cacheable`/`@CacheEvict`/`@CachePut`/`@Caching`，用命中计数验证缓存生效。

**⑬ async** — `@EnableAsync` + `@Async`（自定义线程池、返回 `Future`、`AsyncUncaughtExceptionHandler`）；`@EnableScheduling` + `@Scheduled`（fixedDelay/cron，`CountDownLatch` 验证触发）。
